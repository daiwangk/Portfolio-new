## 🚀 About This Portfolio

A modern, animated developer portfolio built with **React + Vite + Framer Motion**. Features a cinematic splash intro, AI orb parallax background, typewriter hero, interactive project cards, and a fully responsive layout — all in a premium dark mode aesthetic.

---

## ✨ Features

- **Splash Intro** — Cinematic loading screen shown once per session
- **AI Orb Background** — Animated parallax orb that reacts to scroll
- **Typewriter Hero** — Rotating animated role titles (AI Solutions / ML Pipelines / Backend Systems / Automation Workflows)
- **Animated Timeline** — Work experience section with glowing connector lines
- **Project Showcase** — 7 projects with Problem / Built / Learned breakdown + GitHub links
- **Skills Grid** — Categorized skill tags with glassmorphism cards
- **Learning Section** — Current focus areas with live status badges
- **Responsive Design** — Works on mobile, tablet, and desktop
- **Framer Motion** — Smooth scroll-triggered animations throughout

## ⚡ Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/daiwangk/Portfolio-new.git
cd Portfolio-new

# Install dependencies
npm install

# Start the development server
npm run dev
```

The site will be running at `http://localhost:5173`

### Build for Production

```bash
npm run build
npm run preview
```

## 🌐 Deployment

This portfolio is deployed on **Vercel**. Every push to `main` auto-deploys.

To deploy your own fork:
1. Fork this repo
2. Go to [vercel.com](https://vercel.com) → Import Project
3. Connect your fork → Deploy
